# New School — מתכננים למידה לבוחן

יחידת למידה בעברית לתכנון הכנה לבוחן בשלושה נושאים לאורך שלושה ימים. היחידה כוללת חמישה שלבי למידה, תוכנית לדוגמה ושאלון מסכם.

## הפעלה

החבילה מיועדת לפעילות SCORM 1.2 ב־Moodle. יש להעלות את קובץ ה־ZIP בשלמותו; `imsmanifest.xml` ו־`index.html` נמצאים בשורש החבילה. להפעלה מקומית יש להגיש את תוכן התיקייה באמצעות שרת HTTP, למשל Live Server ב־VS Code. בעת הפעלה מחוץ ל־Moodle ניתן להשתמש בשאלון, אך התוצאות אינן נשמרות ב־LMS.

## השאלון והדיווח

- חמש השאלות הראשונות מדורגות ורף המעבר הוא 60 מתוך 100. אפשר להגיש גם בציון נמוך מהרף לאחר השלמת כל השאלות.
- שאלה 6 היא שאלת חובה ללא ניקוד. התשובה נדרשת לכלול לפחות 15 מילים ושני מושגים שונים מתוך יעד לימודי, משימות קטנות, חזרה ותרגול; המגבלה היא 255 יחידות UTF-16.
- בהגשה נשלחים הציון ותוצאות חמש השאלות המדורגות ל־SCORM. התשובה הפתוחה נשמרת גם ב־`cmi.suspend_data` וגם נשלחת כאינטראקציית `fill-in` ללא ניקוד. בדוח Moodle האינטראקציות עשויות להיות ממוספרות החל מ־0.
- הצגת התשובה הפתוחה בשלמותה בדוח תלויה בגרסת Moodle ובהגדרותיה; יש לאמת זאת בניסיון חדש לאחר העלאת החבילה.

## קבצים

- `index.html` — עמוד הלמידה והניווט.
- `activities/` — תוכנית הלמידה והשאלון המוטמעים בעמוד.
- `css/`, `js/` ו־`assets/` — עיצוב, לוגיקה ומשאבים.
- `imsmanifest.xml` — הגדרת חבילת SCORM 1.2.
- `credits.html` ו־`CREDITS.md` — קרדיטים ורישיונות.

לפני הגשה מומלץ לבדוק את החבילה ב־Moodle באמצעות ניסיון חדש: מענה והגשה, רישום ציון ותשובות, הצגת שאלה 6 וחזרה לעמוד הפעילות. מומלץ גם לבדוק ניווט מקלדת ומסכים קטנים.
